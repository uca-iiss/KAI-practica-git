# Que es la informatica

La informatica es la disciplina que estudia:

- El tratamiento automatico de la informacion
- El diseno de algoritmos
- La construccion de sistemas de software y hardware

Idea clave: datos + procesos = informacion util.

---

# Componentes basicos

## Hardware

- CPU
- Memoria RAM
- Almacenamiento (SSD/HDD)
- Perifericos

## Software

- Sistema operativo
- Aplicaciones
- Herramientas de desarrollo

---

# Redes y comunicacion

Una red permite que dispositivos compartan recursos y datos.

Conceptos importantes:

- Direccion IP
- DNS
- Router y switch
- Protocolos (TCP/IP, HTTP, HTTPS)

---

# Ciberseguridad

Objetivos principales:

- Confidencialidad
- Integridad
- Disponibilidad

Buenas practicas:

- Usar contrasenas robustas
- Activar doble factor de autenticacion
- Mantener sistemas actualizados
- Hacer copias de seguridad

---

# Inteligencia artificial

La IA permite que los sistemas realicen tareas que suelen requerir inteligencia humana.

Ejemplos:

- Reconocimiento de imagen y voz
- Asistentes virtuales
- Recomendadores
- Deteccion de fraude

---

# Desarrollo de software

Fases comunes:

1. Analisis de requisitos
2. Diseno
3. Implementacion
4. Pruebas
5. Despliegue y mantenimiento

Metodologias frecuentes:

- Agile
- Scrum
- Kanban

---

# Resumen

La informatica combina teoria y practica para resolver problemas reales.

Puntos clave:

- Entender fundamentos de hardware, software y redes
- Aplicar seguridad desde el inicio
- Probar y mejorar continuamente los sistemas
